# 本色 · 草本茶饮空间漫游

以提供的分区平面图为布局依据，以点单、陈列和休息三张图片为风格参考的 WebGL 实时三维网页。店名「本色」为预览占位，可修改。本轮视觉优化遵循已安装的 Taste Skill（`design-taste-frontend`）规则，采用深森林绿、深木、低饱和暖金的单一视觉语言，保留原有空间构造。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```powershell
cd D:\建模\tea-shop-web
npm.cmd install
npm.cmd run dev
```

浏览器访问终端显示的本地地址，默认 http://127.0.0.1:5173 。初次依赖安装完成后，预览不需要访问外部网络。

## 使用

- 鼠标拖动或手机单指滑动环视。
- WASD、方向键或手机方向按钮行走。
- 下方四个区域按钮、空间热点、小地图切换视点。
- 「俯瞰全店」进入屋顶隐藏的全店视角，拖动旋转、滚轮缩放。
- 「暖光氛围」切换日间自然光。
- 「保存视角」下载不带网页界面的三维画面。
- 「设计参考」查看原始平面图和三张风格图。

## 布局与说明

保留入口折线轮廓、左侧台阶、右侧楼梯和机房位置。展示柜靠机房侧墙，陈列面朝营业区，上方为菜单；造景位于机房左上外侧。左下为长椅与三张同款圆桌，侧边一桌两椅。右下为加长点单柜台、短外卖取餐端、顾客取餐端和制作清洗设备，中间留出通道。

原图没有施工尺寸，网页按图片比例估算，并对家具间距作适度调整。三维效果用于布局、材质和风格沟通，不是实测模型或施工图。台阶和员工区域有行走边界；机房内部未设计。原有 Blender 文件保持原样。

## 文件

- `src/scene.js`：空间轮廓、材质、家具与灯光。
- `src/main.js`：第一人称控制、区域视点、碰撞检测、小地图和交互。
- `src/base.css`、`src/taste-overrides.css`、`index.html`：响应式网页界面与视觉优化层。
- `public/references/`：本次提供的四张参考图。
- `screenshots/`：桌面、手机和各区域实测截图。
- `preview_check.py`：浏览器功能验证脚本，需要 Python Playwright 和本机 Chrome。

## 构建

```powershell
npm.cmd run build
npm.cmd run preview
```

`dist/` 可部署到静态网站服务器。由于使用 ES 模块，不建议直接双击 HTML 文件打开。
